# Original channel logo

Put this channel's original PNG/JPG logo here as `logo.png` (or update branding.json to the exact local filename). The renderer loads it before recording the first frame, fits the full image without cropping, and keeps it above captions. Never copy a different channel's logo here. A missing optional logo keeps the existing channel name while the original asset is pending; the renderer records logoApplied=false.

The news logo currently installed is extracted without redrawing from the video supplied by the user. The three inline still images were visible in chat but no downloadable original image files were supplied to this workspace; their original assets remain pending.
