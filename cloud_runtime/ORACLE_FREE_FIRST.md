# Oracle المجاني أولًا: خطوة حسابية قبل التشغيل

لم ننشئ حسابًا أو موردًا. المستخدم ينشئ حساب Oracle Cloud ويتحقق من أهلية العرض في منطقته. لا يلزم وضع بيانات البطاقة أو كلمة السر في الدردشة.

1. اختر Home Region بعد التأكد من وجود سعة؛ السعة المجانية ليست مضمونة. راجع شروط Always Free الحالية وميزانيات حسابك في لوحة Oracle، فالحدود قد تتغير. أرصدة التجربة المجانية المؤقتة تختلف عن Always Free.
2. المرشح للرندر هو **VM.Standard.A1.Flex (Ampere ARM64)** إذا ظهرت عليه أهلية **Always Free** داخل حسابك. الحدود الشائعة تاريخيًا هي 4 OCPU و24 GB RAM موزعة على مثيلات A1، و200 GB تخزين Block إجمالي؛ هذه أرقام مرجعية غير متحقق منها مباشرة هنا. تأكد من المتبقي الفعلي بالحساب، بما فيه قرص الإقلاع وأي أقراص أخرى، قبل الإنشاء. لا تختَر shape مدفوعًا أو ترقية Pay As You Go كبديل تلقائي عند نفاد السعة.
3. اختر Ubuntu ARM64 المتوافق مع A1، وأضف مفتاح SSH عام من Android. لا تفعّل نسخًا احتياطية أو أقراصًا أو عنوانًا/خدمات إضافية مدفوعة. راجع صفحة التكلفة النهائية وأهلية الموارد قبل الضغط على الإنشاء. لا نفترض أن رقمًا مثل 0 أثناء التجربة يعني مجانيًا دائمًا.
4. **اختبار التوافق أولًا:** requirements تضم ASR وCTranslate2 وPyAV وTorch. لم نثبت توافر وتوافق جميع wheels مع إصدار Python على ARM في هذا الحساب. تحقق عبر تثبيت معزول ومراجعة اختبار كامل للصوت والرندر؛ لا تتجاوز فشل ASR أو تخفض تحقق الجودة لتشغيل A1. إرشادات README العامة لـx86 ليست ضمانًا أن ARM يعمل بنفس الأوامر.
5. إذا لم تتوافر سعة A1 مجانية، توقف واعرض الحالة للمستخدم. لا تحجز x86 مدفوعًا أو ترفع الحدود تلقائيًا. مثيلات x86 الصغيرة المجانية المعتادة ليست هدفًا مناسبًا لرندر الأربع قنوات بجودة 1080p والتحقق الصوتي.
6. بعد اكتمال التوافق فقط: اربط الدومين وHTTPS والمفاتيح بأمان، ثم مراجعة علمية واحدة، ثم باقي المراجعات، ثم تفعيل الجدولة بعد الموافقة. راقب المساحة والحصص وأهلية Always Free. قد يسترد المزود الموارد الخاملة وفق شروطه؛ الخدمة المجانية ليست ضمان توافر دائم.

الخطوة المطلوبة من المستخدم الآن هي **إنشاء حساب Oracle أو فتح حسابه، ثم التأكد من توافر A1 Always Free**. هذه الحزمة جاهزة للمراجعة محليًا لكنها لم تُنشر على Oracle، ولم تُستهلك أموال أو حصص API أثناء إعدادها.
