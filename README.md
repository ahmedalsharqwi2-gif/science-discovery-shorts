# ai على السريع — Egyptian AI News

مصنع أخبار AI عمودية 1080×1920 / 30fps، مستقل عن قنوات العلوم والتاريخ والرعب. خطه البصري مستوحى من العينتين المرفوعتين: خلفية داكنة، بطاقات ومقارنات عربية، موشن مستمر، ترجمة من توقيت الصوت، مصدر وتاريخ واضحان. لا يستخدم تسجيلات العينات أو يعيد أخبارها بلا تحقق.

## مسار واحد

RSS رسمي حديث خلال 72 ساعة ← مقال رسمي غير مستخدم ← سكربت Gemini Flash Lite مصري مع شواهد مصدرية ← مراجعة معلومات منفصلة ← تعليق كامل بصوت **Charon** المعتمد ← Whisper لقياس توقيت الكلمات ← رسوم عربية وموسيقى أصلية مولدة بالكود ← فحص طول الصوت ونهاية الكلام ← MP4 للمراجعة.

لا يوجد نشر سوشيال أو Buffer في هذا المشروع. عند عدم وجود خبر حديث موثوق يسجل سبب عدم إنتاج فيديو. الـASR يضبط المزامنة، وليس إثباتًا لصحة الحقائق أو ضمانًا للنطق مئة بالمئة.

## إعداد GitHub

1. هذا هو مستودع القناة المستقل: ai-news-daily.
2. أضف Secret باسم `GEMINI_API_KEY` من مشروع Google الذي تريد تخصيص حصته لهذه القناة. اختياريًا افصل الكتابة والصوت باستخدام `GEMINI_TEXT_API_KEY` و`GEMINI_TTS_API_KEY`.
3. شغّل **ai على السريع** يدويًا. يظهر الفيديو ضمن Artifacts مع المصدر والتحقق.
4. بعد مراجعة العينة، فعّل Repository Variable: `AI_NEWS_DAILY_ENABLED=true` لتشغيل الإنتاج يوميًا 13:10 بتوقيت القاهرة. لا تنشر هذه الخطوة على السوشيال.

لكل حلقة عادةً طلبا كتابة وطلب صوت كامل؛ حد الأمان 12 كتابة وطلبا صوت للتشغيل، و40 كتابة و6 صوت لليوم. الحصة الحقيقية تتبع مشروع Google، وليست مستقلة لكل مفتاح. القناة الرابعة لو شاركت مشروعًا قائمًا ستشارك حصته. لا تتضمن الحزمة مفاتيح ولا تتطلب الاشتراك بخدمة مدفوعة. تحتاج التأكد من Free tier للمشروع كما في الحسابات المعروضة.

## تشغيل محلي

Python 3.11+ وFFmpeg و`python -m pip install -r requirements.txt` ثم `python -m news.produce` بعد ضبط المفتاح في البيئة. الخطوط Noto مرفقة بترخيصها. الصور يولدها Cloudflare FLUX بأوصاف Gemini، والموسيقى والمؤثرات مولدة محليًا. التلخيص البصري يشرح المعلومات ولا يختلق نتائج Benchmark.

## إعادة المحاولة

يحفظ GitHub Actions الصوت وسجل الطلبات بين التشغيلات. يحفظ مسودة الحلقة وتوقيتها داخل نفس رقم التشغيل لإعادة محاولة فشل الرندر دون توليد سكربت أو صوت جديد. سجل عناوين المصادر يمنع إعادة نفس الخبر بعد نجاح الفيديو. يُحتفظ بالنواتج 30 يومًا؛ للحفظ الأطول نزّل الفيديو أو اربط أرشيفًا دائمًا قبل الإنتاج المستمر.

## النسخة الكوميدية

Gemini يكتب سكريبت ميمز مصري جديد من مصدر رسمي، ثم يراجعه مقابل المصدر. كل قفلة لها توقيت من الصوت الفعلي، ورسمة رد فعل أصلية وزووم ومؤثر قصير. Charon يقرأ النص كاملًا في طلب واحد. الأرقام مكتوبة بالحروف.

عينة الفرع تستخدم مصدر الخبر السابق فقط لإعادة تقييم الأسلوب؛ لا تستخدم سكريبت العينة السابق. الجدول يبدأ الإنتاج 13:10 بتوقيت القاهرة؛ النشر يحتاج ربط قنوات المستودع الرابع وتأكيده منفصلًا.
