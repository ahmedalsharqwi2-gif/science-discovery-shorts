# Remotion factory integration

Remotion4.0.540 renders each original measured-voice frame at1080x1920/30fps. The existing narration, keys, topic histories and scheduled posts are preserved. History and horror require documented real events; only stickman what-if premises are fictional.

The first new films use separately recorded original repository Charon narration. Captions remain phrase-level, preserving raw independent ASR and honest unmatched-word reports. Full decode, exact frame count, audio duration and speech-tail correlation are checked before a movie is marked rendered. Artistic review must inspect the actual resulting footage; technical success alone is not approval.

Archival source URLs, public-domain/CC0 provenance, source and output hashes, Natural Earth pinned data, and renderer source hashes accompany each film. Static typography and drawings are not passed off as real photographs. The retained delivery artifact is recovered before any retry; a previous synthesis intent without recoverable original audio stops, never silently synthesizes again.

No review image or incomplete film is sent to social platforms. Daily cutover remains gated by the full new film evidence and the latest owner visual direction.
