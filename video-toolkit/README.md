# حزمة أدوات الفيديو

حزمة مستقلة لمستودعات التاريخ والعلوم والرعب. تثبيت المكتبات والتحقق من تشغيلها خطوة تجهيز؛ تشغيل إنتاج الفيديو الحالي لا يستعملها تلقائياً. ربطها بسيناريوهات الحلقات والصوت والصور يحتاج تنفيذ قوالب الإنتاج.

## الأدوات المثبتة

- Motion Canvas: تصميم مشاهد ورسوم توضيحية وتوقيت الحركة؛ معه المحرر وVite plugin.
- PixiJS: صور متعددة الطبقات ومؤثرات ثنائية الأبعاد.
- GSAP: التحكم في توقيت الحركة ومساراتها، مع seek حتمي أثناء تصدير الإطارات.
- Three.js: كاميرا وإضاءة ومشاهد ثلاثية الأبعاد.
- Remotion وReact: تركيب المشاهد وتصدير MP4 بترتيب إطارات مضبوط.
- Playwright وChromium: تشغيل وفحص المتصفح دون واجهة.
- FFmpeg وFFprobe: ترميز الفيديو وفحصه، يثبتان في GitHub Actions.

الإصدارات مقفلة في package-lock.json. كل تشغيل GitHub Actions يحصل على آلة جديدة ويعيد npm ci مع cache؛ لا يوجد تثبيت دائم على خادم GitHub.

## التشغيل

من Actions اختر **Video Toolkit Check** ثم **Run workflow**. بعد نجاحه نزّل **video-toolkit-verified**: فيديو اختبار مدته ثانيتان، صورتان للمؤثرات وتقرير تحقق. هذا اختبار تقني، وليس عينة المستوى الفني النهائي.

محلياً مع Node 22 وFFmpeg:

```bash
cd video-toolkit
npm ci
npx playwright install --with-deps chromium
npm run check
```

يفحص التشغيل بناء مشهد Motion Canvas، ويشغّل PixiJS وGSAP وThree.js في Chromium مع مقارنة إطارين، ثم ينتج فيديو Remotion ويفحص أبعاده ومدته ومعدل إطاراته وفك ترميزه كاملاً.

- src/effects.ts: مثال للطبقات والتحكم بالحركة ومشهد ثلاثي الأبعاد.
- motion/scene.tsx: بداية مشهد Motion Canvas.
- src/video.tsx: تركيب Remotion تجريبي.
- scripts/check.mjs: فحص التشغيل والرندر.

يمكن بناء مشهد Motion Canvas بالأمر npm run build:motion. ملفا إعداد Vite مستقلان لأن كل محرك له طريقة بناء مختلفة. لا يجب خلط محركات الرندر في حلقة واحدة؛ اختر المناسب لكل قالب، واستخدم ملفات صور/فيديو وسيطة عند الدمج.

## الجودة والصوت

المكتبات لا تولد صوراً ولا تحسن صوتاً مسجلاً ولا تنشئ أداءً صوتياً جديداً. الإنتاج الاحترافي يحتاج صوراً معتمدة، إخراجاً لكل مشهد، صوتاً جيداً وتوقيتاً يطابقه. لا توجد مفاتيح خدمات أو اشتراكات مدفوعة أو نشر اجتماعي في هذه الحزمة. عينة دنكرك المعتمدة في مستودع التاريخ تعمل بمحركها المحفوظ في history_visual دون تغيير.
